# Sakura 手机远程端 · 使用手册

> 把手机变成 Sakura 桌宠的第二个屏幕。
> **AI 计算和语音合成都留在电脑**，手机只负责显示和播放 —— 所以手机不发烫、不耗电，
> 换手机也不用重新配置模型。

## 1. 它是什么

```
┌─────────────────────────┐              ┌──────────────────────────┐
│        手机              │              │          电脑             │
│                         │   WiFi/组网   │                          │
│  ┌───────────────────┐  │  ──────────▶ │  ┌────────────────────┐  │
│  │ Sakura App        │  │              │  │ Sakura 主程序       │  │
│  │ ├ 立绘显示         │  │              │  │ ├ 对话模型          │  │
│  │ ├ 文字气泡         │  │  ◀────────── │  │ ├ TTS 语音合成      │  │
│  │ ├ 语音播放         │  │              │  │ ├ 长期记忆          │  │
│  │ └ 桌面立绘/小球     │  │              │  │ └ 手机远程端插件     │  │
│  └───────────────────┘  │              │  └────────────────────┘  │
└─────────────────────────┘              └──────────────────────────┘
```

**关键点：电脑必须开着、Sakura 必须运行。** 这是远程串流，不是离线可用。

### 能做什么

| 功能 | 说明 |
| --- | --- |
| 对话 | 和电脑端**同一个角色、同一份记忆**，手机电脑看到的是同一段对话 |
| 立绘联动 | 按回复语气自动切换表情，手机全屏显示 |
| 语音 | 电脑合成、手机自动播放，形成连续说话感 |
| 图片 | 发相册图片或拍照 |
| 截屏 | 让角色「看到」你手机屏幕上的内容 |
| 桌面立绘 | 角色待在手机桌面上，可拖动、可缩放、点一下回到对话 |
| 圆形小球 | 收成一个小头像球，不占地方，点一下展开 |

## 2. 安装前准备

### 电脑端

- Sakura 已安装并能正常对话（先确认电脑上自己能用）
- 电脑和手机在**同一个 WiFi**（远程使用见第 12 节）
- 知道电脑的局域网 IP（后面会教怎么查）

### 手机端

- Android 8.0 或更高
- 需要授予三项权限，**都要手动确认**，系统不会自动给：
  - 悬浮窗（显示在其他应用上层）—— 桌面立绘必需
  - 通知 —— 后台保活必需
  - 电池优化白名单 —— 降低被系统清理的概率

> 小米/红米（MIUI）还需要额外打开**「后台弹出界面」**权限，
> 否则从桌宠点回对话会被系统拦截。

## 3. 安装电脑端插件

### 3.1 放文件

把发布包里的 `plugin/sakura.remote/` 整个目录复制到：

```
<Sakura安装目录>/plugins/user/sakura.remote/
```

**目录名必须是 `sakura.remote`** —— 它就是插件 id，改名会认不出来。

### 3.2 启用

打开 Sakura → 设置 → **手机远程端** → 打开「启用手机远程端」开关。

### 3.3 关键配置

| 字段 | 建议值 | 说明 |
| --- | --- | --- |
| 监听地址 | `0.0.0.0` | 必须是这个，手机才能通过 WiFi 连上 |
| 端口 | `8770` | 默认即可 |
| **访问 token** | **改成随机长串** | 默认值是 `sakura`，**务必改掉** |

> **安全提醒**：`0.0.0.0` 意味着同网段设备都能访问这个端口，靠 token 保护。
> 请改成足够长的随机串，并且**不要把端口映射到公网**。
> 需要外网访问请用第 12 节的组网方案。

改完重启 Sakura 生效。

### 3.4 在设置面板上直接抄连接信息

面板上有三个只读字段，可以直接复制：

| 字段 | 用途 |
| --- | --- |
| 访问 token | 手机要填的口令（明文显示，可复制） |
| 本机链接 | 在电脑浏览器里预览效果 |
| **手机直接打开这个地址** | **完整地址（含 token），复制到手机浏览器就能用** |
| 内网链接 | 同一 WiFi 下手机可访问的地址 |

## 4. 安装手机端 App

把 `SakuraRemote-release.apk` 传到手机安装。

> 这是**自签名**的 release 包，安装时系统会提示「未知来源」，手动允许即可。
>
> 如果之前装过 debug 版，两者签名不同**不能覆盖安装**，要先卸载旧的。

## 5. 第一次连接

1. 打开 App，填写：
   - **电脑地址和端口**：形如 `192.168.1.100:8770`
   - **访问 token**：第 3.3 节设置的那一串
2. 点「测试连接」→ 成功后点「进入」
3. 进入后点右上角**设置**，完成两件事：
   - **手机桌面** → 开启桌面立绘（会弹悬浮窗权限）
   - **手机桌面** → 申请后台保活（会弹电池优化白名单）

### 怎么查电脑的局域网 IP

电脑上打开命令行，输入 `ipconfig`，找「IPv4 地址」，形如 `192.168.1.100`。

或者在 Sakura 的插件设置面板里直接看「内网链接」，复制过来就行。

在底部输入框打字 → 点「发送」。

- 悬浮窗里只显示**当前这一句**，用对话框右侧的 **▲ ▼** 翻上一条/下一条

### 长按桌宠（悬浮窗里）

| 操作 | 效果 |
| --- | --- |
| 长按 **5 秒**不动 | 打开设置页 |
| 长按后**拖动** | 移动角色位置 |
| 双指捏合 | 缩放角色大小 |
| **轻点透明处** | 点到底下的桌面图标（悬浮窗不会挡住桌面） |

## 7. 语音功能

### 怎么工作

每段文字用**日文原文 + 语气**送到电脑端合成，合成好的音频传回手机自动播放。
下一段在你听上一段时就已经合成好了，所以听起来是连贯的。

### 开启

| 位置 | 开关 |
| --- | --- |
| 配置页 → 语音 | 「收到回复自动朗读」「允许电脑合成语音」 |
| 悬浮窗顶部 | **语音** 按钮（快速开关） |

> **首次播放需要一次触摸。** 手机浏览器/WebView 规定必须有用户交互才允许播放声音，
> 这是系统限制，绕不过去。轻触屏幕任意处即可解锁（会看到「轻触屏幕任意处即可开启语音」提示）。

### 延迟说明

电脑端 TTS 合成每段要约 **3–6 秒**。文字和立绘是**立刻**出现的，语音随后跟上。
这是正常现象，不是卡顿。

## 8. 图片与截屏

点输入栏左边的 **＋** 按钮，弹出两个选项：

| 选项 | 说明 |
| --- | --- |
| 选择图片 | 从相册或拍照选一张 |
| 截取屏幕 | 让角色看到你手机当前屏幕 |

### 已选内容提示

选了图片、或截了屏之后，输入栏上方会出现一条提示，显示：

- **缩略图** —— 一眼看出是哪张
- **文件名和大小** —— 例如 `IMG_20260923_004512.jpg（2.3 MB）`
- **截图序号** —— 例如「截图 2（已发送）」，让你知道截了几张
- 右侧 **×** —— 取消已选图片

图片的提示会一直保留到你发送；截图的提示 8 秒后自动消失。

### 截屏的首次授权

第一次点「截取屏幕」，系统会弹出**屏幕录制授权**对话框，点「立即开始」。
授权一次后，本次 App 运行期间不用再授权。

> **截屏时会自动隐藏桌宠**，所以拍出来的图里不会带着角色和对话框。
> 截完会自动恢复。

## 9. 桌面立绘（桌宠模式）

让角色待在手机桌面上。这是 Android 上唯一能把应用内容画在桌面之上的方式。

### 开启

配置页 → 手机桌面 → **开启桌面立绘**（需要悬浮窗权限）。

也可以点「收起 App，回桌面看立绘」。

### 桌宠上的操作

| 操作 | 效果 |
| --- | --- |
| 拖动 | 移动位置 |
| 双指捏合 | 缩放大小 |
| 长按 5 秒 | 打开设置 |
| 轻点 | 不影响（留给语音解锁） |
| 轻点**透明区域** | 点到下层桌面图标 |

### 窗口大小

窗口大小 = **立绘 + 对话框 + 输入栏**，随角色缩放自动变化。
拖动「角色大小」滑块，窗口会跟着变大变小。

## 10. 缩小成圆形小球

不想让桌宠占地方时，收成一个小头像球。

### 怎么缩小

两种方式：

1. 悬浮窗里，输入栏上方有个 **⊙ 缩小** 按钮
2. 配置页 → 手机桌面 → **缩小成圆形小球**

缩小后窗口只剩一个小圆球，里面是角色的头像。

### 小球上的操作

| 操作 | 效果 |
| --- | --- |
| **轻点** | 恢复成完整窗口 |
| **长按 1.5 秒** | 打开设置 |
| **拖动** | 移动小球位置 |

> 小球的窗口只有 56dp（不到 1 厘米见方），几乎不占桌面，也不会挡住图标 ——
> 点它旁边的透明区域照样能点到桌面图标。

## 12. 远程连接（不在同一个 WiFi）

任何能让手机访问到电脑该端口的方案都行，例如
**Tailscale / ZeroTier / 蒲公英** 这类组网工具。

**做法**：两端加入同一个虚拟网络，App 里把地址填成**电脑的虚拟 IP**。

### 需要多少带宽

实测数据：

| 场景 | 平均带宽 |
| --- | --- |
| 只看立绘 + 打字 | 几乎为 0 |
| 语音对话（说话占约 30%） | 约 150 kbps |
| 语音几乎不停 | 512 kbps |
| 首次进入 | 瞬时 2–3 MB（之后走缓存） |

**3 Mbps 以上很舒服，1 Mbps 勉强可用。** 4G 完全够。

## 13. 故障排查

### 连不上

按顺序检查：

1. 手机和电脑在**同一个 WiFi**
2. 电脑上 Sakura **正在运行**
3. 插件设置里「启用手机远程端」是**开**
4. 监听地址是 **`0.0.0.0`**
5. **电脑防火墙**放行 8770 端口
6. token 完全一致（区分大小写，注意别多复制空格）

### 有文字但没有立绘

角色资源不完整。检查电脑上 `<Sakura>/characters/<角色id>/` 里有没有立绘 PNG。

### 桌面立绘打不开

1. 悬浮窗权限是否授予（系统设置 → 应用 → Sakura → 显示在其他应用上层）
2. 通知权限是否授予
3. MIUI 还要开「后台弹出界面」

### 点了截屏没反应

1. 第一次会弹**屏幕录制授权**，要点「立即开始」
2. 授权对话框如果在后台看不到，先切回 App 再点一次

### 桌上的角色点不动

轻点在**角色的透明区域**会穿过到桌面 —— 这是设计如此。
点在角色本体上才有反应。

### 语音不出声

1. 先**轻触一下屏幕**解锁音频（系统限制）
2. 检查「收到回复自动朗读」是否开着
3. 检查手机媒体音量

### 桌宠过一会儿消失了

省电策略把它清理了。去配置页点「申请后台保活」，
并在系统设置里把 Sakura 的电池策略设为**「无限制」**。

### 改配置没反应

多数配置项**需要重启电脑端 Sakura**。用配置页的「重启电脑端 Sakura」按钮。

## 14. 常见问题

### 手机能切换电脑端的角色吗？

能，但**需要重启 Sakura 才生效**。

原因：手机端只能改电脑端的角色配置文件，而电脑端启动后就不再读它了。
所以配置页切换后会出现「待重启」标记，点「重启电脑端 Sakura」即可。

### 为什么截屏要隐藏桌宠？

MediaProjection 拍的是**整块屏幕**，桌宠也在屏幕最上层。
不隐藏的话，角色和对话框会被拍进截图里。

### 电脑关了会怎样？

连不上，App 会提示「无法连接电脑端」。
因为模型和语音都在电脑上，这是设计如此。

### 换手机要重新配置吗？

要重新填地址和 token，但**电脑端不用动**。角色、记忆、模型都在电脑上。

### 悬浮窗会挡住桌面图标吗？

不会。轻点角色的**透明区域**就会穿透到桌面图标。
关键是点在透明处 —— 点在角色本体会被角色接住。

### 数据存在哪里？

| 位置 | 内容 |
| --- | --- |
| `<Sakura>/data/plugins/sakura.remote/config.json` | 插件配置（token 等） |
| `<Sakura>/data/plugins/sakura.remote/logs/` | 运行日志、访问日志 |
| `<Sakura>/data/plugins/sakura.remote/cache/` | 图片上传缓存 |
| 手机 `localStorage` | 显示偏好（大小、位置、字号等） |

## 15. 技术说明

### 为什么手机这么省电

所有 AI 计算、TTS 合成都在电脑端。手机只做三件事：
接收立绘和文字、播放音频、绘制界面。

### 带宽都花在哪

立绘 PNG 平均 1.36 MB（15 张共 19.9 MB，只下载一次并缓存）。
语音是 32 kHz 单声道 WAV，**64 KB/s** —— 10 秒语音约 640 KB。

想更省流量可以用 AAC/Opus 编码，能再降约 10 倍。

### 数据流

```
手机输入文字/图片
   ↓
插件 /api/chat
   ↓
sakura.host.mobile  →  电脑端对话模型（含长期记忆）
   ↓ 返回带语气的分段回复
插件按语气映射立绘 → 手机显示
   ↓
每段日文原文 + 语气 → 电脑端 TTS → WAV 回传 → 手机播放
```

### 版本

- 插件版本：1.0.0
- 插件 API：4
- 最低 Android：8.0
