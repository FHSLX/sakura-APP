# Sakura 手机远程端 — 安装说明

包含两部分，可分别使用：

```
SakuraRemote-release.apk    安卓客户端
插件/sakura.remote/          Sakura 插件（装到电脑端）
```

---

## 一、安装插件（电脑端）

把 `插件/sakura.remote/` 整个目录放到 Sakura 的插件目录下：

```
<Sakura>/plugins/user/sakura.remote/
```

**目录名必须是 `sakura.remote`**（它就是插件 id）。

然后在 Sakura 里启用：设置 → 手机远程端 → 打开开关。

### 配置

`插件/sakura.remote/config.json` 是默认配置：

```json
{
  "enabled": false,
  "host": "0.0.0.0",
  "port": 8770,
  "token": "sakura",
  "autoplay": true,
  "tts_enabled": true
}
```

| 字段 | 说明 |
| --- | --- |
| `host` | 监听地址。手机要通过 WiFi 连，必须是 `0.0.0.0` |
| `port` | 监听端口，默认 8770 |
| `token` | 访问口令，**默认值 `sakura` 请务必改掉** |
| `autoplay` | 收到回复自动朗读（也可在手机端改） |
| `tts_enabled` | 允许电脑端合成语音（也可在手机端改） |

改完重启 Sakura 生效。

> **安全提示**：`host` 用 `0.0.0.0` 会让同网段的设备都能访问这个端口，
> 靠 `token` 保护。请把 token 改成足够长的随机串，并且**不要把端口映射到公网**。
> 需要外网访问请用 Tailscale 之类的带鉴权通道。

## 二、安装 App（手机端）

把 `SakuraRemote-release.apk` 传到手机安装。

> 这是**自签名**的 release 包。安装时系统会提示「未知来源」，需要手动允许。
>
> 如果之前装过 debug 版，两者签名不同**不能覆盖安装**，要先卸载旧的。

### 装好后要做的三件事

1. **连接电脑**：打开 App，填电脑的局域网 IP 和端口
   （形如 `192.168.1.100:8770`）以及 token，点「测试连接」→「进入」。
2. **授予悬浮窗权限**：设置 → 手机桌面 → 开启桌面立绘，
   系统会弹「显示在其他应用上层」。**这个权限只能手动授予。**
3. **允许通知 + 申请后台保活**：否则省电策略可能把桌宠杀掉。

部分系统（如 MIUI）还需要额外打开「后台弹出界面」权限，
否则从桌宠点回对话可能被拦截。

## 三、配置页能做什么

App 里点右上角「设置」，或**长按桌面立绘 5 秒**打开：

| 区块 | 内容 |
| --- | --- |
| 连接 | 电脑地址、token（可显示 / 复制）、当前角色、语音状态 |
| 显示 | 角色大小、立绘上下位置、浮动开关、字体大小、对话框位置、双语字幕 |
| 角色 | 角色列表，可切换（需重启 Sakura 生效） |
| 语音 | 自动朗读、允许电脑合成语音 |
| 手机桌面 | 开关桌面立绘、申请后台保活 |
| 快捷操作 | 语音开关、清空本机显示 |
| 怎么配置 | 软件内操作说明 |

滑块旁边都有数字输入框，可以直接敲数值精调。

### 切换角色的限制

切换角色是**改电脑端的配置文件**，而电脑端不监听该文件，
所以**改完要重启 Sakura 才生效**，界面会标出「待重启」。

这是折中方案：宿主的接口只允许手机端和**当前角色**对话，
没有提供切换角色的接口。

## 四、快速自检

| 现象 | 先查什么 |
| --- | --- |
| App 连不上 | 同一 WiFi；插件已启用；防火墙放行端口；token 一致 |
| 没有立绘只有文字 | 插件里角色是否可用（`<Sakura>/chars/` 下有角色资源） |
| 点开启桌面立绘没反应 | 悬浮窗权限、通知权限是否授予 |
| 表情不跟随语气 | 看插件日志 `<Sakura>/data/plugins/sakura.remote/logs/` |
| 语音要等几秒 | 电脑端 TTS 合成需要 3–6 秒/段，属正常 |

## 五、远程使用（可选）

任何能让手机访问到电脑该端口的方案都可以，例如
**Tailscale / ZeroTier / 蒲公英** 这类组网工具。

做法：两端加入同一虚拟网络，App 里把地址填成**电脑的虚拟 IP**。

带宽参考（实测）：

| 场景 | 平均带宽 |
| --- | --- |
| 只看立绘 + 打字 | 几乎为 0 |
| 语音对话（说话占约 30%） | 约 150 kbps |
| 语音几乎不停 | 512 kbps |
| 首次进入 | 瞬时 2–3 MB（之后走缓存） |

**3 Mbps 以上很舒服，1 Mbps 勉强可用。**
